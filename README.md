## Project Goal
Train and evaluate deep learning models on a footwear image dataset with different categories (e.g., sneakers, sandals, boots, formal shoes).

## Suggested Repository Structure
```
.
├── data/
│   ├── raw/           # original dataset (do not commit large files)
│   └── processed/     # cleaned/split data
├── notebooks/         # EDA and experiments
├── src/               # training, evaluation, and utilities
├── models/            # saved model artifacts (tracked only if small)
├── reports/           # results, plots, confusion matrices
└── README.md
```

## Quick Start
1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies from `requirements.txt` (when added).
4. Place dataset files under `data/raw/`.
5. Start experiments in `notebooks/` or `src/`.

## Collaboration Workflow
