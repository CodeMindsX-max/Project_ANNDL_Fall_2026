# Contributing Guide

Thanks for contributing to this project.

## Branching
- Branch from `main`.
- Use clear branch names, e.g. `feature/data-loader`, `fix/train-loop`.

## Commit Messages
Use short and descriptive commit messages:
- `feat: add dataset split utility`
- `fix: handle missing image labels`
- `docs: update training instructions`

## Pull Requests
- Keep PRs focused and small.
- Fill out the PR template.
- Link related issues when possible.
- Request review from at least one teammate.

## Coding Notes
- Keep notebooks clean and reproducible.
- Do not commit large datasets, model binaries, or secrets.
- Track experiments clearly in PR descriptions.
